# Серверный план расширения «Подхода»

Объём и критерии: [план iOS](https://github.com/nekell3r/podhod-ios/blob/main/docs/ROADMAP.ru.md). Пользователь включил питание, рецепты и КБЖУ. Android не дорабатывается; совместимость его запросов проверяется при изменении API.

| Направление | Серверная задача | Условие реализации |
|---|---|---|
| IOS-01: рабочая тренировка | Явные `removedSetIDs` в active/history: удаление незавершённого подхода с оценкой запаса, офлайн и защита выполненного | Выпущено перед совместимым iOS, SQL-схема не менялась |
| IOS-02: замены | Исходная карточка сохраняется целиком; замена добавляется с пустыми подходами и новыми UUID | Существующий active/history контракт, без SQL-миграции |
| IOS-04: циклы/суперсеты | Отдельный cycle, снимки типа дня и ссылки групп на подходы; защита старых клиентов и history | API выпущен в main workflow 10; iOS 1.7.9 выпущен после него. Контракт — TRAINING-CYCLES-CONTRACT.ru.md |
| IOS-05: прогресс | Отчёты, графики и рекорды рассчитываются из неизменной истории на iOS | Выпущено без нового агрегатного API |
| IOS-06: рецепты | Импортированы 24 продукта USDA и 16 собственных рецептов, закреплены источники и единицы | Каталог в `internal/service/nutrition-catalog.json`; 7 проверок импорта |
| IOS-07: питание | API дней/целей/своих рецептов/избранного реализован на существующем storage, без SQL-миграции | API и клиент 1.7.8 выпущены; проверки и границы — в плане iOS / QA-IOS07 |
| IOS-08: фото/замеры | iOS 1.7.10 хранит данные приватно на iPhone по аккаунтам, без загрузки на API | Новый серверный контракт/SQL не требуется; локальный контракт — в iOS docs/BODY-PROGRESS-CONTRACT.ru.md |
| IOS-09: Live Activity | iOS 1.7.11 показывает отдых через ActivityKit/WidgetKit и локальное уведомление | Выпущено без APNs и нового API; время принадлежит телефону |
| IOS-10: база знаний | Шесть собственных материалов, прежний каталог техники и локальные закладки аккаунта/гостя | Выпущено в iOS 1.7.12; новый API/SQL не требуется |

Все серверные зависимости согласованного программного бэклога реализованы и опубликованы. Последний функциональный деплой API — [main workflow 10](https://github.com/nekell3r/podhod-backend/actions/runs/41248140761), commit `5dad7b87157da1e83c79fa461da2e69e3c5cbce4`; race/vet, отдельная PostgreSQL и серверный receipt прошли. Последний функциональный пакет iOS — [1.7.12 (1012)](https://github.com/nekell3r/podhod-ios/actions/runs/41257750065), 225 core-тестов и 23 проверки упаковки. Полная фактическая UI-проверка и аппаратные ограничения описаны в QA клиентов. Библиотека именованных программ и AI исключены по решению пользователя; Android-код не менялся.

SQL-схема не изменена: fingerprint `internal/storage/postgres.go` остаётся `c2e5a605de412f2b5566d347b365b2ebacff161b07b21d53e4bca32610cdae61`. Фото/замеры и закладки знаний не загружаются в API; облачное хранение этих ресурсов не заявляется.

API и миграции описываются в API.md и проверяются с отдельной тестовой PostgreSQL. Источники схемы проходят deployment fingerprint gate, изолированную репетицию и отдельное одобрение. Автоматически менять разрешённый hash нельзя. Наличие экрана не означает готовность хранения и синхронизации.
